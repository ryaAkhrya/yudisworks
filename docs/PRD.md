# Product Requirement Document (PRD): yudisworks

## 1. Objective
Membangun website portofolio interaktif dan dinamis untuk menampilkan jasa freelance "Palugada" (Web Dev, Makalah, PPT) milik Yudistira. Web harus memiliki estetika hardcore terinspirasi dari UI game "Persona 5" (P5), dengan pendekatan *mixed language* (UI bahasa Inggris, konten bahasa Indonesia).

## 2. Target Audience
- Mahasiswa lokal yang butuh joki tugas/makalah/PPT cepat dan berkualitas.
- Klien bisnis kecil/menengah yang butuh website responsif.

## 3. Core Features
- **Hero Section:** Intro agresif dengan CTA "Drop Your Request" ke WhatsApp.
- **The Arsenal (Services):** Katalog jasa (Web, Akademik, Presentasi).
- **The Heists (Portfolio):** Etalase karya bergaya *classified documents*.
- **The Phan-Site (Testimonials):** Forum anonim bergaya *live-chat scrolling* untuk bukti kepuasan klien.
- **Admin Studio (CMS):** Backend lokal di rute `/studio` terintegrasi via Supabase untuk manajemen portofolio dan testimoni secara mandiri.
