# yudisworks

Portfolio website for Yudistira, built with a strictly enforced Persona 5 aesthetic. High performance, zero AI-slop.

## Setup Instructions
1. Clone the repository.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and add Supabase URL, Anon Key, and Service Role Key (if needed for admin).
4. Run `npm run dev`.
